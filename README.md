# MANIFIESTOS-TRABAJOS-AI

Intenciones aprobadas y constituciones de trabajos nuevos gobernados por
[METODO-AI](https://github.com/francogg89-ai/METODO-AI).

## Estructura

| Path | Función |
|---|---|
| `manifiestos/<WORK_ID>/MANIFIESTO_TRABAJO.md` | Intención aprobada |
| `manifiestos/<WORK_ID>/PROJECT.md` | Vinculación con proyecto, sólo cuando corresponde |
| `manifiestos/<WORK_ID>/CONSTITUCION_INICIAL.md` | Referencias exactas, acceso y capacidades de arranque |

Las reglas de publicación y plantillas están en `METODO-AI/CONSTITUIR.md` y `METODO-AI/plantillas/`.
La ejecución concreta fija METHOD_SHA; una actualización de main no cambia el trabajo constituido.
Este README orienta, no duplica esas reglas. No se incluyen trabajos de ejemplo ejecutables.

Publicar intención sólo después de aprobación humana explícita. Obtener su commit antes de
preparar la constitución que lo referencia. No guardar secretos, avances, últimos actores,
contadores ni paquetes de reanudación aquí. Work y audit conservan ejecución y evidencia.
Mantener paths estables y versiones en Git. Cada trabajo tiene identidad propia aunque reutilice carril.
